# Codex Bar 0.0.8

## 新功能

- **通知权限快捷引导**：当系统通知未授权或已关闭时，可从设置页直接前往 macOS 通知设置完成授权。

## 改进

- **支持最新模型计价**：新增 GPT-6.1 Sol、GPT-6 Sol、GPT-6 Luna 等模型的 Token 费用估算，并正确计算 GPT-6.1 Sol 更低的缓存输入价格。
- **权限状态自动同步**：从系统设置返回后会立即重新检查通知权限，授权成功后自动隐藏引导入口。
- **中英文界面补全**：通知权限引导会跟随系统语言显示中文或英文。

## 问题修复

- 修复打开详细面板时，首次额度请求尚未开始便被误判为断开连接的问题。现在会正确区分“正在连接”与真实连接失败。

## 安装提示

- 此版本已使用 Developer ID 签名，但因开发者协议状态暂未完成 Apple 公证。若 macOS 阻止首次打开，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## What's New

- **Notification permission shortcut**: Open the relevant macOS notification settings directly when notifications are not authorized or have been disabled.

## Improvements

- **Latest model pricing**: Added token-cost estimates for GPT-6.1 Sol, GPT-6 Sol, GPT-6 Luna, and other newly listed models, including GPT-6.1 Sol's lower cached-input rate.
- **Automatic permission refresh**: Notification authorization is checked again when you return from System Settings, and the guidance disappears automatically after access is granted.
- **Localized guidance**: Notification permission controls follow the system language in Chinese and English.

## Bug Fixes

- Fixed a false disconnected state that could appear before the initial quota request started. The app now distinguishes “Connecting” from an actual connection failure.

## Installation Note

- This build is Developer ID signed but not Apple-notarized because the developer agreement is currently inactive. If macOS blocks the first launch, allow it from System Settings → Privacy & Security.
