# Codex Bar 0.0.7

## 新功能

- **通知权限快捷引导**：当 Codex Bar 检测到系统通知未授权或已关闭时，设置页会显示“打开通知设置”入口，方便直接前往 macOS 通知设置完成授权。

## 改进

- **新模型计价**：更新至 2026 年 10 月 1 日的 OpenAI 官方定价，新增 GPT-6.1 Sol、GPT-6 Sol、GPT-6 Luna 等模型的 Token 费用估算，并正确区分 GPT-6.1 Sol 更低的缓存输入价格。
- **权限状态自动同步**：从系统设置返回 Codex Bar 后，应用会立即重新检查通知权限；授权成功后，引导入口会自动隐藏。
- **中英文界面补全**：新增的通知权限引导会跟随系统语言显示中文或英文。

## 问题修复

- 修复详细面板打开时，在首次额度请求尚未开始的短暂阶段被误显示为断开连接的问题。现在会先获取额度，并正确区分“正在连接”与真实的连接失败。

## What's New

- **Notification permission shortcut**: When Codex Bar detects that system notifications are not authorized or have been disabled, Settings now provides a direct shortcut to the relevant macOS notification settings.

## Improvements

- **New model pricing**: Updated the bundled OpenAI pricing to October 1, 2026, including GPT-6.1 Sol, GPT-6 Sol, GPT-6 Luna, and other newly listed models, with GPT-6.1 Sol's lower cached-input rate handled separately.
- **Automatic permission refresh**: Codex Bar rechecks notification authorization as soon as you return from System Settings, then hides the shortcut automatically after access is granted.
- **Localized guidance**: The new notification permission controls are available in both Chinese and English and follow the system language.

## Bug Fixes

- Fixed a false disconnected state that could appear when opening the detailed panel before the initial quota request had started. The app now fetches quota data first and clearly distinguishes “Connecting” from an actual connection failure.
