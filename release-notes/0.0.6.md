# Codex Bar 0.0.6

## 新功能

- **额度重置倒计时**：5 小时和每周额度现在会直接显示距离下次重置还有多久，查看额度时不再需要自行换算日期。

## 改进

- **关键数字滚动效果**：额度百分比、总 Token 用量和费用金额在首次加载或发生变化时，会以更自然的里程表动画呈现；其他辅助数据保持轻量过渡，减少视觉疲劳。
- **更简洁的菜单栏信息**：5 小时额度只显示百分比，每周额度保留“周”标识，让双额度展示更紧凑、更容易扫读。
- **更稳定的卡片布局**：优化额度标题和倒计时的空间分配，避免“5 小时”等标题在较窄卡片中被截断。

## 问题修复

- 修复同时启动多个 Codex Bar 实例时，旧菜单栏图标可能保留但点击无响应的问题。

## What's New

- **Quota reset countdowns**: Five-hour and weekly quota cards now show exactly how long remains until the next reset, so you no longer need to calculate it from the reset date.

## Improvements

- **Focused number animations**: Quota percentages, total token usage, and estimated costs now use an odometer-style transition when they first appear or change. Supporting values use a lighter transition to keep the interface calm.
- **Cleaner menu-bar usage**: The five-hour quota is shown as a percentage, while the weekly value keeps its “W” label, making the combined display more compact and easier to scan.
- **More resilient card layout**: Improved spacing between quota titles and countdowns so labels such as “5 Hours” remain readable in narrow cards.

## Bug Fixes

- Fixed an issue where launching multiple Codex Bar instances could leave an unresponsive menu-bar icon behind.
