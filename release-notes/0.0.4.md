# Codex Bar 0.0.4

## 新功能

- **登录时自动启动**：现在可以在设置中开启“登录时启动”。登录 Mac 后，Codex Bar 会自动运行，无需每次手动打开；如果系统需要额外授权，应用会引导你前往“登录项”设置。

## What's New

- **Launch at Login**: You can now make Codex Bar start automatically whenever you log in to your Mac. If macOS requires approval, the app will guide you directly to Login Items in System Settings.
