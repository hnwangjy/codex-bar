# Codex Bar 0.0.5

## 新功能

- **本地 Token 用量统计**：现在可以查看今天、近 7 天或近 30 天的 Token 用量，并按模型了解输入、缓存输入、输出和推理 Token 的构成。统计仅在本机读取 Codex 会话日志，不分析或上传对话内容。
- **费用估算**：根据官方 Token 单价展示 API 等价费用，并在主面板和菜单栏弹窗中快速查看。没有可靠单价的模型会明确标记为“未计价”，不会混入总额。
- **人民币与美元切换**：费用支持人民币或美元显示。汇率可以手动刷新，并会在每天本地时间 08:00 自动保存最新可用汇率；英语系统首次使用时默认显示美元。

## 改进

- **更清晰的用量面板**：增加统计周期切换、模型费用明细和紧凑的菜单栏费用卡片，让额度与 Token 消耗可以在同一处查看。

## What's New

- **Local token usage**: View token usage for today, the last 7 days, or the last 30 days, including per-model input, cached input, output, and reasoning totals. All analysis stays on your Mac and does not read or upload conversation content.
- **Cost estimates**: See API-equivalent costs based on official token prices in both the main panel and menu popover. Models without a reliable price are clearly marked as unpriced and excluded from the total.
- **CNY and USD display**: Switch costs between CNY and USD, refresh the exchange rate manually, or let Codex Bar save the latest available rate automatically at 08:00 local time each day. English systems default to USD on first use.

## Improvements

- **Clearer usage overview**: Period controls, model-level cost details, and a compact menu-bar cost card bring quota and token usage into one view.
